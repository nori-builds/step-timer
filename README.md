# おなべタイマー（step-timer）

料理の手順と時間を、1本のタイマーにまとめたアプリです。手順を順番に案内しながら、時間を計ります。

> このファイルを、このアプリの仕様の **唯一の正（SSOT）** とします。
> 仕様を変えるときは、先にこの README を更新し、それからコードを直してください。
> 名前「おなべタイマー」は仮です。

## かんたんな使い方

**さいしょに1回だけ**: iPhone の Safari で https://nori-builds.github.io/step-timer/ を開き、共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから開きます。

1. ホームでレシピ（例: 温泉卵）をタップ
2. 手順の一覧を見て、必要なら時間を「今回だけ」変える → 「はじめる」
3. 画面の案内どおりに進める。時間が来たらチャイムと声で知らせる
4. 終わったら、時間を変えた手順について「次からこの時間にする？」と聞かれる

**こんなときは**

- 時間を足したい・減らしたい → タイマーの「−30秒」「＋30秒」
- 早めに次へ進みたい → 「次へ」
- 火を止めて待ちたい → 「一時停止」
- 途中でやめたい → 「ながおしで やめる」を長押し
- レシピを直したい → 始める前の画面の「なおす」

---

## 1. 目的

- 料理のたびに「何分だっけ」と調べる手間をなくす
- 「次は何をするんだっけ」と迷うストレスをなくす
- 茹で時間などは家ごとに違うので、使うたびに自分の家の時間に直していける

## 2. 使う人と端末

| 項目 | 決定 |
|---|---|
| 使う人 | 料理をする大人（自分・家族） |
| 端末 | iPhone |
| 開き方 | Safari で開き、「ホーム画面に追加」してアプリとして使う |
| 表記 | 漢字かな混じり。大きな数字、残り時間は円 |

## 3. 機能仕様

### 3.1 レシピと手順

- 1つのレシピは、上から順に進む手順の並び。同時に動かせるのは **1つのレシピだけ**
- レシピが持つもの: 名前、必要な物（材料や道具。文章）、手順
- 手順が持つもの:

| 項目 | 内容 |
|---|---|
| やること | 例「水を入れてすぐ蓋をする」。**声で読み上げるのはこれだけ** |
| 時間 | 秒。**なし** も選べる（例: お湯が沸いたら次へ） |
| 火加減 | 強火／中火／弱火／火を止める／なし |
| コツ | 小さく表示する。読み上げない |
| 次への進み方 | 「タップで次へ」か「自動で次へ」（時間がある手順だけ） |

### 3.2 最初から入っているレシピ

- 初めて開いたときに、次のレシピが入っている。時間は **一般的な目安** で、家に合わせて直す前提（画面にもそう書く）
  - 半熟ゆで卵 / 固ゆで卵 / 温泉卵 / パスタ / 蒸しブロッコリー / 茶碗蒸し
  - 温泉卵は、余熱で火を通す作り方（沸騰の手前で火を止め、卵を入れて蓋をして11分置く）。参考: https://delishkitchen.tv/recipes/153667539426083235
- 自由に直したり消したりできる。直したものは、編集画面の「最初の状態に戻す」で戻せる
- 消したものは、設定の「消した 最初のレシピを 戻す」で戻せる
- アプリを直して最初のレシピを入れ替えたときは、開いたときに保存済みのレシピにも反映する
  - なくなったレシピは消す（直していても消える）。新しいレシピは足す
  - 自分で消したレシピは、勝手に戻さない（`steptimer.presetsSeen` に、一度入れたレシピを覚えておく）

### 3.3 ホーム

- レシピを大きなボタンで並べる。表示は「手順 4つ ／ タイマー 約10分」（タイマーは時間がある手順の合計）
- **並び順は自分で変える**。左の つまみ（⠿）をつかむか、カードを長押し（約0.45秒）してから上下に動かす。並び順は保存する
  - 長押しの途中で指が動いたら（スクロールしたら）つかまない
  - 新しく作ったレシピ・取り込んだレシピは、いちばん下に入る
- 「＋ 新しいレシピ」で、**文章から作る**（おすすめ）か、一から自分で作るかを選ぶ。くわしくは [3.8.1](#381-文章から作る)
- **ホームから消せる**。下の「レシピを消す」を押すと、各カードに「消す」ボタンが出る。押すとすぐ消え、約6秒間「元に戻す」が出る。「消しおわった」で元の画面に戻る
  - 料理中の誤操作を防ぐため、ふだんのホームには消すボタンを出さない
- 「＋ 新しいレシピ」で自分で作れる

### 3.4 始める前の画面

- 必要な物と、手順の一覧（火加減・時間・次への進み方）を出す
- 時間がある手順をタップすると、**今回だけ** 時間を変えられる（例: パスタの袋の時間）
- 「ほかのアプリに切り替えたり画面を消したりすると、音が鳴りません」と出す
- 「なおす」でレシピ編集へ。「はじめる」で音の確認をしてからスタート

### 3.5 タイマー

- 時間は **手順を始めた時刻からの経過** で計算する。アプリを切り替えたり開き直したりしても、ずれずに続きから表示する
- 動いている途中の状態は端末に保存し、開き直すとタイマー画面に戻る
- 画面の色は **今の手順の火加減** で変わる（強火=赤、中火=だいだい、弱火=黄色、火を止める=青、なし=白っぽい）
- 表示: 手順の番号（2 / 5）、火加減（大きく）、残り時間と円、やること、コツ（小さく）、次の手順
- 手順が始まるときに「やること」を読み上げる
- **時間なしの手順**: 「できたら 次へ」の大きなボタンだけ出す
- ボタン:

| ボタン | 動き |
|---|---|
| −30秒 / ＋30秒 | 今の手順の時間を足し引きする（10秒より短くはならない） |
| 一時停止 / 再開 | 止めている間は時間が進まない |
| 次へ | 今の手順を終えて次へ |
| ながおしで やめる | **1.2秒長押し** したときだけ止まる |

- 上のボタン以外は、画面を触っても何も起きない

### 3.6 時間が来たとき

- **自動で次へ**: チャイムを1回鳴らし、次の「やること」を読んで、そのまま次の手順を始める
- **タップで次へ**: 知らせの画面を出す
  - 画面全体が点滅し、「つぎは ○○」と次の手順を大きく出す
  - **画面のどこをタップしても次へ** 進む（濡れた手や手の甲でも押せる）
  - タップするまで、約8秒おきにチャイム＋読み上げを繰り返す。**1分たったら鳴らすのをやめる**（画面はそのまま）
  - 「＋30秒 のばす」ボタンで、今の手順を延長できる
- 最後の手順のときは「できあがり！」と出す
- ほかのアプリから戻ってきたとき、もう時間が過ぎていたら「○分○秒前に 終わっています」と出して、音を鳴らす

### 3.7 時間を覚える（チューニング）

- 終わったとき、次の手順について「○○ 3:00 → 2:30 にする？」とチェック付きで並べる
  - **±30秒を押した手順** → 足し引きしたあとの時間
  - **時間が来る前に「次へ」を押した手順** → そこまでにかかった時間（5秒単位に丸める。一時停止の間は数えない）
  - **始める前に今回だけ変えた手順** → その時間（こちらは最初はチェックなし）
- チェックした手順だけ、レシピに保存する。変わった手順がなければ何も聞かない
- アラームが鳴ってからタップするまでの時間は数えない

### 3.8 レシピ編集

- 名前、必要な物、手順（やること・時間・火加減・コツ・次への進み方）
- 手順は ↑↓ で並べ替え、✕ で消す、「＋ 手順を足す」で足す
- 「複製」（例: 半熟と固ゆでを分ける）、「消す」、「最初の状態に戻す」（最初から入っていたレシピだけ）、「送る」

#### 3.8.1 文章から作る

レシピサイトの「材料」と「作り方」をコピーして貼り付けると、レシピの下書きを作る。下書きは編集画面で開くので、確かめて「保存」する。サーバーや AI は使わず、アプリの中の決まりで読み取る（URL から直接は読めない。ブラウザの決まりで、ほかのサイトを読めないため）。

| 読み取るもの | 決まり |
|---|---|
| 名前 | 最初の短い行。「〜の作り方」は取る。「〜する」のように動きで終わる行は手順とみなす |
| 必要な物 | 「材料」「用意するもの」などの見出しの下の行 |
| 手順 | 「1.」「①」「STEP 1」、番号だけの行などで区切る。番号がなければ1行を1手順にする |
| 時間 | 文の中の「3分」「1分30秒」「1時間」。「10〜12分」は真ん中（11分）。「1分短く」「5分前」「3分の1」は時間とみなさない。時間がある文は、それだけで1つの手順に分ける |
| 火加減 | 「強火」「中火」「弱火」「火を止める」「余熱」「電子レンジ」などの言葉。書いていない手順は、前の手順の火加減を引きつぐ |
| コツ | 「※」「ポイント:」で始まる行、文の最後の（ ）の中 |

- 次への進み方は、すべて「タップで次へ」にする
- 「貼り付け」ボタンは、iPhone では確認が出てから貼り付く。出ないときは入力欄を長押しして「ペースト」

### 3.9 保存と共有（サーバーなし）

- **ファイルに保存**: 全部のレシピを1つのファイル（JSON）にする。iPhone では共有シートの「"ファイル"に保存」で iCloud Drive に置ける。機種変更しても残る
- **読み込む**: ファイルを選ぶか、送られてきたリンクを貼り付けて取り込む
- **リンクで送る**: レシピを縮めて URL の `#r=` の後ろに入れる。1つでも、全部でも送れる。LINE などで家族に渡す
  - リンクを開くと「このレシピを取り込む？」と出る
  - 注意: LINE から開くと、ホーム画面のアプリではなく Safari などで開く。**ホーム画面のアプリに入れたいときは**、出てきた画面の「コピー」でリンクをコピーし、アプリの設定 →「読み込む」に貼り付ける
- 同じ名前のレシピがあるときは、上書きせずに「（2）」を付けて別に足す

### 3.10 音・画面

- MeltTime と同じ仕組みを使う
  - チャイムはその場で合成する。声は iPhone の読み上げ（高品質な日本語の声を自動で選ぶ）。設定で声をオフにできる
  - 「はじめる」のときに「おとが でるよ」の確認をして、音を鳴らす準備をする。途中で音が止まったら「音が止まっています」の確認を出す
  - マナーモードでも鳴るように `navigator.audioSession.type = 'playback'` と、無音の音声の再生を使う
  - 動いている間は画面を消さない（Wake Lock API）。使えないときは「画面をつけたままにしてね」と出す
- iPhone のウェブアプリでは、ほかのアプリに切り替えたり画面をロックすると音が鳴らない（サーバーからの通知は使わない）

### 3.11 キャラクター「おなべの子」

- 小さなお鍋の子。SVG をコードで描く（画像ファイルや著作権の心配なし）
- 火加減で様子が変わる: 強火=ぐつぐつ（蓋がゆれて湯気がたくさん）、中火=ふつう、弱火=ぽかぽか、火を止める=すやすや、時間が来た=びっくり、できあがり=にっこり
- ホーム画面のアイコンとファビコンもこの子

### 3.12 つかいかた

- ホームの右上の「?」で開く。はじめて開いたときだけ自動で出す

## 4. 作っていないもの

- サーバー、ログイン、家族の端末との自動同期
- プッシュ通知（画面をつけっぱなしにする方式で代わりにしている）
- 2つ以上のレシピを同時に動かすこと
- 「1つ前の手順に戻る」（料理は時間を巻き戻せないので、±30秒で直す）
- 作った記録（スタンプ）
- フレームワーク

## 5. 技術構成

| 項目 | 決定 |
|---|---|
| 構成 | `index.html` 1ファイル（HTML / CSS / JS を中に書く）＋アイコン画像 |
| 保存 | `localStorage`（その iPhone の中だけ） |
| 公開 | GitHub Pages（https） |
| フォント | ヒラギノ丸ゴ（iPhone に最初から入っている） |

### 保存キー

| キー | 内容 |
|---|---|
| `steptimer.recipes` | レシピの配列 `{ id, name, items, presetId, uses, lastUsed, steps: [{ text, sec, heat, tip, next }] }` |
| `steptimer.settings` | `{ voice }` |
| `steptimer.run` | 動いているタイマー（止まっているときは無し） |
| `steptimer.helpSeen` | つかいかたを一度閉じたら `true` |

- `sec` は秒（時間なしは `null`）。`heat` は `strong` `medium` `weak` `off` `none`。`next` は `tap` `auto`
- テストモードでは、キーの先頭が `steptimer-test.` になる

### 注意（iPhone）

- **ホーム画面から開いたときと Safari で開いたときでは、保存が別々になる**。Safari で開いているときは、その説明を画面上部に出す
- 音と読み上げは、タップのときに有効にしている
